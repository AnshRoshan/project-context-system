compiled context for coding agents

Your repo, knowable from files.

The model isn't your bottleneck. Your repo is. This skill makes your agent write down what it learns, once, into a markdown wiki. Every later session starts already knowing the project.

node <clone>/scripts/ctx.mjs setup

One command. Any language. Greenfield or brownfield. Re-run any time: it upgrades in place.

the cost of forgetting

Same model. Two repos. Different worlds.

Without a wiki, every session re-explores the codebase from zero. With one, orientation is a few thousand tokens of files written once, at change time. Drag the session counter.
